# Module Specification — Viral Analyzer

## Purpose

Reverse-engineer the creative mechanics of a user-supplied reference URL and notes, then produce a brand-safe adaptation for Workspace assets.

## Analysis Dimensions

Hook, storytelling, CTA, camera, lighting, emotion, caption, hashtags, audio, scene, clothing, expression, pose and rhythm.

## Inputs

- Source URL.
- Transcript, caption or observations.
- Optional Digital Human.
- Optional product.

## Outputs

- Structured analysis.
- Platform inference.
- Viral Score.
- Adapted prompt.
- Persisted analysis record.

## Rules

The system may adapt mechanics and structure. It must not instruct users to copy a creator identity, protected brand identity or exact copyrighted wording.

The current analyzer is heuristic. Future integrations may enrich it with authorized transcription, vision, audio and public-metric providers.
